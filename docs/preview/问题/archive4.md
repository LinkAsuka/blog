# 页面跳转不成功,复制到浏览器可以打开
<!-- more -->

## 解决办法

有些网站写 a 标签跳转后跳过去的的页面显示不成功,但是复制地址再到浏览器回车就能够显示出来
`会出现这样的问题是因为有些网站为了防止爬虫做了处理`

```html
<a href="https://www.aaa.com/" target="_blank" rel="noopener noreferrer">
  跳转到一个新页面
</a>
```

加了`rel="noopener noreferrer"`之后就能够跳过去

## 原理说明

1. noopener:•	当您在一个链接中使用 target="_blank" 时，新的浏览器标签页或窗口会获得对原始页面的窗口对象访问权限（通过 window.opener）
    -	这意味着新标签页或窗口可以通过 window.opener 来访问和操作打开它的原始页面。这在某些情况下可能导致安全问题，例如执行恶意脚本或重定向用户
    -	使用 rel="noopener" 可以防止新窗口访问原始窗口，确保安全性
2.	noreferrer:•	当您使用 noreferrer 时，除了阻止新标签页访问原页面外，它还会阻止浏览器发送 HTTP 引荐头（Referer Header）。这意味着新窗口无法知道用户是从哪个页面点击进入的
    -	这有助于保护用户隐私，特别是在从一个网站导航到另一个网站时。为什么有些网站加了这句话就能“跳过去”
    -	有时网站使用 rel="noopener noreferrer" 来实现更好的用户体验。通过使用这些属性，网站可以减小潜在的安全风险（如通过 window.opener 的跨窗口攻击）
    -	加上这两个属性后，用户点击链接时会确保新的页面不会影响原页面的状态，从而避免了可能的重定向或弹窗干扰
    -	这也可能是一种优化策略，减少由于页面之间不必要的相互访问而导致的性能开销

## 总结

使用 `rel="noopener noreferrer"` 是一种常见的安全实践，特别是在链接到其他站点时，能有效保护原始页面，防止新窗口操控原窗口，同时也保护用户的隐私。
